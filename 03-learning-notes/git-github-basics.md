# Git & GitHub Basics

## What is Git?
Git is a version control system that helps me track changes in my projects.

## What is GitHub?
GitHub is a platform where I can store, maage, and share my projects.

## What is a repository?
A repository is a projects space where my files and their history are stored.

## What is a commit?
A commit is a saved change in my projects.
